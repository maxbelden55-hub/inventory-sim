# Change log: issues found, root causes, fixes, verification

Each entry: what broke → why → what changed → how the fix was confirmed. Numbers are from the
actual runs. Ordered by when the issue surfaced.

|---|---|---|---|---|---|
| 1 | Data download | `onlineretail.rda` reported as `ASCII text, with no line terminators` (14 bytes) | Download loop tried a `main` branch URL after the working `master` URL; the 404 body overwrote the good file | Download from the single working URL | `file` reports `XZ compressed data`; `pyreadr` loads 541,909 rows |
